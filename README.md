# CS PATH

A bilingual personal computer science learning path.

Explore 18 courses, readings, homework, labs and projects. Plan weekly study time, check foundational readiness, and follow an interactive prerequisite map. Course availability changes can be used to replan while preserving explicit progress.

中文：个人计算机学习路线，包含课程、学习材料、先修自检、可视化路线及时间规划。

The first visit follows the browser’s preferred supported language. Manual language choice and progress stay in the browser.

Run locally: python3 -m http.server 8766

Open http://127.0.0.1:8766/ . No installation step is needed.
